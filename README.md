# سایت عاشقانه Baroon

این پوشه شامل فایل HTML ارسال‌شده و فایل صوتی Baroon است. تنها اصلاح فنی انجام‌شده، هماهنگ کردن مسیر صوتی HTML با نام فایل `Baroon.mp3` است.

## انتشار با GitHub Pages

1. یک مخزن عمومی جدید در GitHub بسازید، مثلاً با نام `baroon-love`.
2. فایل‌های `index.html` و `Baroon.mp3` را در ریشه مخزن بارگذاری کنید.
3. در `Settings → Pages`، انتشار از شاخه `main` و پوشه `/(root)` را انتخاب کنید.
4. بعد از تکمیل انتشار، لینک نهایی شبیه `https://USERNAME.github.io/baroon-love/` خواهد بود.

فایل صوتی باید کنار `index.html` باشد؛ نام فایل به حروف بزرگ و کوچک حساس است.
